## 🔧 Configuration

### First Time Setup

1. **Install Python** (if not installed)
   - Windows: https://python.org/downloads/
   - Mac: `brew install python3`
   - Linux: `sudo apt-get install python3`

2. **Install Git** (if not installed)
   - Windows: https://git-scm.com/download/win
   - Mac: `brew install git`
   - Linux: `sudo apt-get install git`

3. **Configure Git**
   ```bash
   git config user.name "Your Name"
   git config user.email "your@email.com"
   ```

4. **Run Setup**
   - Windows: Double-click `setup.bat`
   - Mac/Linux: `bash setup.sh`

### GitHub Integration

1. Create a GitHub repository
2. Copy the URL (format: `https://github.com/yourusername/creator_kid.git`)
3. In admin panel → Settings tab
4. Paste URL and click "Set Remote"
5. Click "Push to GitHub"

## 🔄 How It Works Behind the Scenes

### When You Add a Prompt:

```python
# Admin Panel catches the form submission
# ↓
# data_manager.py generates ID (CK006)
# ↓
# Reads current js/data.js
# ↓
# Adds new item to prompts array
# ↓
# Writes back to js/data.js
# ↓
# git_manager.py auto-commits
#   Message: "[ADD] CK006 - 2024-01-15 14:30:45"
# ↓
# You can push to GitHub anytime
# ↓
# Website reads latest data.js
# ↓
# New prompt appears on website!
```

### When You Upload an Image:

```python
# You select image file
# ↓
# data_manager.py copies to assets/images/
# ↓
# Stores reference: "assets/images/filename.jpg"
# ↓
# Writes path to data.js
# ↓
# Auto-committed to Git
# ↓
# Website can access image
# ↓
# Displays image to visitors!
```

## 🚨 Troubleshooting

### "Python not found"
- Install from https://python.org
- Make sure to check "Add to PATH"
- Restart command prompt

### "Git not found"
- Install from https://git-scm.com
- Make sure to check "Add to PATH"

### "Can't find data.js"
- Check that you're in the right directory
- Verify path in config.py

### "Images not uploading"
- Check write permissions on assets/images/
- Try creating files/folders manually
